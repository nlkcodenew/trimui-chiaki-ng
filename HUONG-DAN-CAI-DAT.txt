HƯỚNG DẪN CÀI ĐẶT CHIAKI-NG
(Chạy được cả stock OS và Knulli OS — Brick Pro, Smart Pro S, cùng một bản build)

File ZIP duy nhất trong release chứa đủ mọi thứ cho cả hai hệ điều hành
(thư mục App/ cho stock OS, thư mục system/ + roms/ cho Knulli OS, và
file hướng dẫn này). Tùy máy đang chạy hệ điều hành nào mà làm theo
phần A hoặc phần B dưới đây.

================================================================
PHẦN A — STOCK OS (hệ điều hành gốc của máy)
================================================================
1. Tải file ZIP của bản release về máy tính, giải nén ra sẽ được các
   thư mục App/, system/, roms/ và file HUONG-DAN-CAI-DAT.txt. Chỉ cần
   thư mục App/Chiaki/: chép thẳng ra gốc thẻ nhớ (bỏ qua system/,
   roms/ và file hướng dẫn — chúng dành cho Knulli OS).

2. Cắm thẻ vào máy, mở Chiaki-ng từ mục Apps trên máy.

3. Lần đầu dùng: vào app để ghép nối (pair) với máy PS4/PS5.
   Dữ liệu ghép nối nằm ngoài gói cài đặt nên cập nhật bản mới không
   mất pair.

Lưu ý (stock OS):
- Cập nhật: giải nén/copy đè lên bản cũ, hoặc dùng OTA trong app.
- Khi cập nhật, app KHÔNG ghi đè settings.json, paired_hosts.json,
  chiaki.conf, secrets.json — cấu hình và pair của bạn được giữ nguyên.

================================================================
PHẦN B — KNULLI OS
================================================================
Trên Knulli, app nằm ở mục Tools (không phải Ports). File ZIP đã
chứa sẵn mọi thứ cho Knulli, không cần tải thêm file nào khác.

1. Giải nén file ZIP ra máy tính, sẽ được các thư mục system/,
   roms/ và file HUONG-DAN-CAI-DAT.txt (cùng thư mục App/ dành
   cho stock OS — bỏ qua).

2. Chép thư mục system/chiaki/ vào /userdata/system/ trên máy game
   (gộp/ghi đè — chỉ chép đè, không cần xóa thư mục cũ).
   Cách chép: qua SFTP/SSH, hoặc tháo thẻ gắn vào máy tính rồi chép
   vào phân vùng dữ liệu (thư mục system/ nằm ở gốc phân vùng đó).

3. Chép file roms/tools/Chiaki-ng.sh vào /userdata/roms/tools/
   trên máy game, rồi cấp quyền chạy (qua SSH):
     chmod +x /userdata/roms/tools/Chiaki-ng.sh

4. (Tùy chọn, để hiện icon đẹp) Chép file
   roms/tools/images/chiaki.png vào /userdata/roms/tools/images/.

5. Khởi động lại máy, mở EmulationStation, vào mục Tools rồi chọn
   Chiaki-ng.

Lưu ý (Knulli OS):
- Launcher tự tạo liên kết /mnt/SDCARD trỏ sang /userdata nếu máy chưa
  có.
- Cập nhật: dùng OTA trong app. Cập nhật OTA chỉ cập nhật payload trong
  /userdata/system/chiaki/, không tự chuyển file launcher.
- Dữ liệu ghép nối (settings.json, paired_hosts.json, chiaki.conf,
  secrets.json) không nằm trong gói OTA nên không bị ghi đè.

ĐÃ CÀI BẢN CŨ Ở PORTS, MUỐN CHUYỂN SANG TOOLS:
- Chép file Chiaki-ng.sh từ /userdata/roms/ports/ sang
  /userdata/roms/tools/ (xóa file cũ ở Ports sau khi chép).
- Chép icon chiaki.png từ /userdata/roms/ports/images/ sang
  /userdata/roms/tools/images/.
- Chuyển mục gamelist: dừng EmulationStation trước
  (/etc/init.d/S31emulationstation stop), cắt khối <game> của
  Chiaki-ng từ /userdata/roms/ports/gamelist.xml sang
  /userdata/roms/tools/gamelist.xml (tạo file mới nếu chưa có), rồi
  khởi động lại máy.
